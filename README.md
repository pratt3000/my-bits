# my-bits

A collection of [Plethora](https://create.plethora.studio) Bits — tiny,
mobile-first interactive objects built to the Plethora agent contract.

## Bits

- **[loop-pedal](./loop-pedal/)** — a live looper. Record drums, bass, keys,
  strings and a vocal-style pad into loops that stack on top of each other,
  loop-pedal style. `plethora-bit@2`, permissions: `audio`, `haptics`.
